# RT12：只保留 DP 绕障、看不到箱子就回巡线

由 `shared_nav_20261111_rt10` 复制而来。RT10 的“只留 300 s 停止”不变。

## 相对 RT10 的改动

1. **移除 GapController 穿缝**：`VisualNavigator` 不再创建、不再调用 `GapController`。
   模块文件仍在（供旧测试导入），但整圈运行路径完全不经过。
   所有绕障统一走横向网格 DP（`plan()`，**±1.0 m**、2 cm 一档、纵向 0.135 m / 横向 0.280 m 膨胀）。
   允许压白线：压在车道中心的箱子也能规划出从外侧绕过的路径（20 cm 箱偏移 0.38 m，
   28 cm 箱 0.42 m），不再因为走廊不够宽而报 `blocked`。单次规划约 50 ms（Jetson）。
2. **移除终点**：不再识别、不锁存、不判定过线；`finished` / `finish_target` 全部删除。
   任务从开始走到 300 s，没有“过终点”这一支。
3. **避障退出条件清空**：删除 `box_latched / saw_box / finish_latched / unconfirmed_sites /
   clear_frames` 以及“箱子已在身后 + 附近无箱 + 地面清晰 + 有车道 + 里程计接受”的组合判据。
   新规则只有一条：
   - 进入：当前帧 `scene=='raised_object'`（6–65 cm 高、0.22–1.15 m 前、路径带内），或跟踪器在**当前帧**看到了箱子。
   - 退出：连续 **3 帧** 既没有凸起、跟踪器也没有匹配到箱子 → 回到 `current_lane`
     （单帧遮挡不再立刻退出；`n` 是 `OnboardNavigation.exit_frames`）。
   “当前帧看到”用箱子记录的 `time` 是否等于本帧时间判断；被遮挡的箱子记忆不算看到。
4. **单根白线只在避障里算车道**：巡线调用 `fit_lane(require_known_side=True)`，与 RT10 一致——
   没有历史参考、又不在起跑区时直接拒绝（`edge_side_unknown`），不会靠“线在哪一侧”的猜测修正，
   避免在车道外把中心算到反方向。避障的跟踪器调用 `require_known_side=False`，
   仍可以只用一根线走；避障还额外暴露了“原始边界线”（`raw_lane`），巡线不会使用它。
5. **避障里只有 `no_reference` 会扫视**（既没有白线、也没有 `last_lane`）：
   进入 `search_scan`：+30° → −30° → 回 0° → 直行 1 s，然后重来。
   `blocked`（±1.0 m 走廊内仍无可行路径）不再扫视，改为**朝空间更大的一侧纯横移**
   （`vx=0`、`vy=±0.20`），直到规划重新有解。
   角度用 AHRS 实测角闭环（±1.0 rad/s 满幅、3° 死区），每步 3 s 上限；**每一步结束都要
   等一帧新的处理完的图像再进入下一步**（1.5 s 等不到帧则放行），避免扫视跑在感知前面。
   任何一步看到车道或箱子就退出。
   巡线路径（含 `turn_fault`、无车道、首帧未到）完全按 RT10：没有新车道时 yaw 清零、
   保持上一帧平移，所以转弯时是边转边走，起步时 `last_drive=0` 就站着。
6. **无车道不再是一个状态**：`VisualNavigator` 删掉 `lost_vision` 分支。
   跟踪器没有车道时沿用上一条被接受的车道中心线继续规划（DP 仍用箱子的机身坐标）。
   外层无箱时：有白线照常巡线；**没有白线时按 RT10 保持上一帧平移**（起步时为 0，即站立），
   yaw 清零。转弯时同样保持平移，因此是“边转边走”，不是原地转。

## 行为摘要

- 看到箱子 → `tracking_control=True`，跑完整跟踪器，`near`（−0.25…0.85 m）时绕行。
- **近箱且只看到一根白线时改为贴线**：先 `vx=0`、只朝该线横移，直到线的近段
  （x=0.25 m 处）落在机身中央 ±5 cm；然后沿线前进（`vx=0.12`），横向按
  `1.8·线偏差` 修正、航向跟线的切线。没有单边线时才回到 DP 对齐/绕行。
- **贴线会跨箱持续**：箱子离开 0.85 m 后仍贴这条线（用 AHRS 航向差对记忆线做旋转补偿），
  直到连续 3 帧看不到箱子**且**两条边都拟合出来（`paired_edges`）才退出回巡线；
  最长 72 帧（约 12 s）作为兜底。
- 避障执行分两段：横向目标偏差 >2 cm 时**只横移**（`vx=0`，`|vy|≤0.20`）；
  进入 2 cm 死区后**横向清零、只前进**（不再边走边横移），近箱期间前进速度降到 **0.10 m/s**
  （策略实际横向只有约 0.1 m/s，0.20 的前进速度跟不出 45° 的绕行路径）。
  只横移连续超过 **4.0 s** 仍未对齐时，允许带着残余横向偏差前进，避免被横向限幅锁死。
- 退出避障时若保持向量几乎只有横移（`|vx|<0.05`），把它换成 0.10 m/s 前进，
  避免车身沿着白线侧滑、不回中心。
- 退出避障后连续 **3 帧**仍看不到车道时，用最后已知车道做一次**小角度修正**：
  目标航向 = 最后车道在 0.25 m 处的切线 + （拍图时的航向 − 当前航向），
  `wz = clip(1.5·误差, ±0.25)`，只在最后车道 3 s 内有效；看到车道或重新进入避障即清零。
- 箱子离开当前帧（或不再有凸起）→ 下一帧回到帧同步巡线：有白线跟白线，没白线就直行前进。
- 不会再把避障阶段的横移命令带进巡线状态。
- 避障中 `blocked` / `no_reference` 按 +30°/−30°/回正/直行 1 s 扫视，且每步等新图；
  巡线路径（转弯、转弯故障、无车道、首帧前）与 RT10 完全一致。

## 风险

- 箱子被短暂遮挡（相机丢帧、被另一只箱子挡住）时会立即退出避障，可能朝箱子方向直行；
  下一帧重新看到再进入避障。
- 没有白线时按当前航向直行，弯道会驶出车道，直到重新看到白线。
- DP 在 ±1.0 m 内仍无解（例如两只箱把整个走廊堵死）时 `mode='blocked'`，
  只横移、不前进，朝空间较大的一侧让开。
- 没有终点判定，300 s 前不会因为过线而结束。
